# AGULAB 官网与风险评估平台回滚清单

## 立即回滚条件

出现任一情况立即停止发布并回滚：

- `/` 无法打开。
- `/evaluate` 无法登录或登录后循环跳转。
- `/api/health` 不是 HTTP 200。
- 已有报告丢失、内容异常或图片不可见。
- 新评估无法写入。
- Nginx 持续返回 404、500 或 502。

## 回滚步骤

- [ ] 停止当前新容器，不删除任何数据卷或宿主机目录。
- [ ] 恢复备份的 `nginx.conf` 和 `docker-compose.yml`。
- [ ] 恢复旧 `frontend/dist/` 与旧 `website/dist/`（若原先存在）。
- [ ] 恢复旧后端代码或旧镜像。
- [ ] 保留服务器当前 `.env`、`backend/data/` 和 `requirement/`。
- [ ] 重新启动旧版本容器。
- [ ] 验证 `/evaluate`、`/api/health`、已有报告和报告图片。
- [ ] 记录失败时间、症状、日志和已恢复的版本。

除非确认数据本身损坏，否则不得用旧数据备份覆盖当前
`backend/data/`。如确需恢复数据，必须再次取得用户明确确认。
