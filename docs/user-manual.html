1. 系统简介

SafeEvaluate（消防安全 AI 评估系统）是一套基于大语言模型的消防安全智能评估平台。用户上传消防现场照片或建筑图纸，选择适用的消防法规标准，AI 即可自动识别隐患、对照规范条款、生成结构化的安全评估报告。

1.1 核心能力

📷 图片智能分析 📋 多规则评估 📄 报告自动生成 📊 数据统计分析 🔍 法规条款对照 🖨️ 报告打印/导出 📂 分图批量评估 📚 自定义规则库

1.2 系统导航

登录后，左侧边栏包含以下菜单：

菜单项功能说明
🔍 新建评估上传图片并启动 AI 消防安全评估
📋 历史记录查看所有历史评估记录，支持分页浏览
📐 规则管理管理评估依据的消防法规和检查标准
📊 统计分析查看评估数据总览、趋势和风险分布
[ 截图：系统主界面 — 侧边栏导航 + 顶部栏 ]

2. 登录系统

2.1 登录页面

打开系统网址后，首先进入登录页面。页面分为左右两栏：

  • 左侧品牌面板 — 展示系统名称和简介
  • 右侧登录表单 — 输入用户名和密码进行认证
[ 截图：登录页面 ]

2.2 登录操作

  1. 在用户名输入框中输入您的账号
  2. 在密码输入框中输入密码
  3. 点击"登录"按钮

提示：登录成功后系统会自动跳转到「新建评估」页面。如果已登录状态下访问登录页，会自动重定向到评估页面。

注意：账号由管理员在服务器配置中统一管理。如需新增或修改账号，请联系系统管理员。

3. 新建评估（核心功能）

这是系统的核心页面，用于上传消防现场照片并启动 AI 评估。页面分为三个主要区域：文件上传区、进度/结果面板、规则选择侧栏。

[ 截图：新建评估页面总览 ]

3.1 两种评估模式

页面顶部提供两个模式切换标签：

🔗 单次评估

将所有上传的图片合并为一次评估，生成一份综合报告。适合同一场所的多角度照片。

预计耗时：1-3 分钟

📄 分图评估

每张图片独立评估，生成多份独立报告。适合不同场所或不同楼层的照片。

预计耗时：每张图片 2-4 分钟

使用建议：同一楼层的不同角度照片使用「单次评估」；不同楼层或不同建筑的图片使用「分图评估」。

3.2 上传文件

在上传区域，您可以：

  • 点击上传区域打开文件选择对话框
  • 拖拽文件直接拖入上传区域
  • 支持 JPG、PNG、WebP 等常见图片格式
  • 支持多文件同时上传（按住 Ctrl 或 Shift 多选）

上传后文件以缩略图形式展示，可点击 ✕ 按钮移除单个文件。

[ 截图：文件上传区域 — 已上传多张图片 ]

3.3 选择评估规则

右侧边栏显示可用的评估规则列表，按类别分组：

类别涵盖内容
消防通道与疏散安全出口、疏散通道、应急照明、疏散指示标志
消防设施与器材灭火器、消火栓、自动喷淋、火灾报警系统
电气与火源管理电气线路、配电箱、明火管理、防爆措施
消防安全管理巡查制度、应急预案、消防演练、培训记录
建筑与场所属性防火分区、耐火等级、防火间距、装修材料

勾选需要评估的规则（可多选），未勾选的规则在本次评估中将被跳过。

建议：根据实际场景选择 2-4 条相关规则即可，选择过多可能延长评估时间。

3.4 启动评估

  1. 确认已上传至少一张图片
  2. 在右侧勾选需要使用的评估规则
  3. 确认底部的预估耗时信息
  4. 点击"开始评估"按钮

提交后系统显示加载动画，提示"正在分析评估中"。在评估期间请勿关闭页面或刷新浏览器。

[ 截图：评估进行中的加载状态 ]

3.5 分图模式的进度面板

在「分图评估」模式下，页面会显示实时进度面板：

  • 进度条 — 显示整体完成百分比
  • 任务列表 — 每张图片一行，显示状态图标
  • 状态标识：⏳ 等待中 → 🔄 评估中 → ✅ 完成 / ❌ 失败
  • 失败项会显示重试次数（最多自动重试 3 次）
[ 截图：分图评估进度面板 ]

3.6 评估完成后

评估完成后，页面底部显示结果面板：

  • 单次模式：显示 ✅ 评估完成，点击"查看报告"进入报告页
  • 分图模式：显示成功/失败数量统计，点击"查看全部报告"进入汇总页；如有失败项可点击"🔄 重试失败项"

3.7 异常处理

如果评估失败，页面会显示错误横幅，包含：

  • 错误原因说明
  • 评估记录 ID（即使失败也会保存）
  • "查看错误详情"按钮 — 可查看原始 AI 响应用于调试
  • 重试建议

常见失败原因：AI 服务暂时不可用、API Key 配额耗尽、网络超时。系统内置自动重试机制（最多 3 次），如仍失败请稍后重试。

4. 查看评估报告

4.1 报告页面结构

评估报告包含以下内容区块：

📷 上传图片展示

评估所用的原始图片以缩略图形式展示在报告顶部，方便对照查看。

📋 总体评估

AI 对整体消防安全状况的综合评价，概括主要问题和建议。

📊 统计卡片

指标含义
✅ 过关项符合消防规范的检查项数量
⚠️ 不过关项存在消防隐患的检查项数量
💡 整改建议AI 提出的整改措施数量

🔴 不过关项 — 需要整改

列出所有不合格的检查项，每项包含：

  • 类别标签 — 所属消防规范类别
  • 问题标题 — 简要描述发现的问题
  • 详细说明 — AI 分析的具体情况
  • 法规依据 — 引用的相关法规条款编号

🟢 过关项 — 符合规范

列出所有合格的检查项，格式与不过关项一致，便于全面了解评估结果。

[ 截图：评估报告页面 ]

4.2 报告操作

  • 打印报告：点击"打印报告"按钮，调用浏览器打印功能，可直接打印或另存为 PDF
  • 导出 PDF：点击"导出 PDF"按钮，将报告导出为 PDF 文件

4.3 评估失败的报告

如果某次评估执行失败，报告页面会显示：

  • 失败原因的具体错误信息
  • 可展开的"原始 AI 响应"调试信息（供技术人员排查）
  • "返回历史"和"重新评估"操作按钮

4.4 分图评估汇总页

分图评估完成后进入汇总页面，以卡片列表展示每张图片的评估结果：

  • 每张卡片显示：缩略图（点击可放大）、文件名、风险等级标签
  • 合格的报告显示过关/不过关/建议的统计数字
  • 失败的卡片显示错误原因和返回重评按钮
  • 顶部统计：总图片数、完成数、失败数
[ 截图：分图评估汇总页面 ]

5. 历史记录

历史记录页面以表格形式列出所有评估记录，支持分页浏览。

5.1 列表信息

列说明
评估名称报告的标题（失败的报告会标注"失败"标签）
评估时间评估执行的日期和时间
风险等级低风险（绿）/ 中风险（黄）/ 高风险（红）/ 评估失败（灰）
操作"查看报告"链接，点击跳转到报告详情页
[ 截图：历史记录列表页 ]

5.2 翻页操作

每页显示 10 条记录。使用底部的分页控件进行翻页：

  • 点击 ‹ / › 箭头切换到上/下一页
  • 点击页码数字直接跳转到指定页
  • 当前页高亮显示

提示：点击任意一行记录即可跳转到对应的报告详情页。顶部的"共 N 条"显示评估总数量。

6. 规则管理

规则管理页面用于维护评估所依据的消防法规和检查标准。支持查看、新增、编辑和删除规则。

[ 截图：规则管理页面 ]

6.1 规则列表

规则以表格形式展示，包含以下字段：

列说明
规则名称规则的名称（如"GB 50016 建筑设计防火规范"），下方灰色文字为规则描述
类别彩色标签显示所属类别
来源文档对应的法规文件名称及条款编号
类型"内置"（系统预置，不可删除）或"自定义"（用户添加）
操作编辑按钮；自定义规则额外显示删除按钮

6.2 类别筛选

列表上方提供类别下拉筛选框，可选择查看特定类别的规则，也可选择"全部类别"查看所有规则。

6.3 新增规则

  1. 点击右上角"+ 新增规则"按钮
  2. 在弹出的表单中填写规则信息
  3. 点击"保存"

表单字段说明：

字段必填说明
规则名称是规则的标题，如法规标准名称
上传PDF文档否上传法规 PDF 文件，系统自动提取文本内容填充到描述和来源文档字段
类别是从6个预设类别中选择
描述否规则涵盖的检查内容和适用范围
来源文档否对应 requirement/ 目录下的文档文件名
条款编号否具体的法规条款编号，如"第5.5.18条"

6.4 PDF 智能解析

新增/编辑规则时，可以上传 PDF 格式的法规文档：

  1. 点击上传区域，选择 PDF 文件
  2. 系统自动解析 PDF 文本内容
  3. 解析后的文本自动填充到"描述"字段
  4. 文件名自动填充到"来源文档"字段

提示：PDF 解析功能可大幅减少手动输入。解析后您仍可以手动修改自动填充的内容。

6.5 编辑与删除

  • 编辑：点击规则行的"编辑"按钮，在弹出表单中修改后保存
  • 删除：仅自定义规则可删除，点击"删除"按钮后需确认操作。内置规则不可删除

7. 统计分析

统计分析页面提供评估数据的可视化总览，帮助管理者了解整体消防安全状况。

[ 截图：统计分析页面 ]

7.1 概览卡片

页面顶部四个指标卡片展示核心数据：

指标说明
📊 评估总次数系统累计完成的评估次数
📈 整体合规率所有评估中合规项占比（百分比）
⚠️ 不合规项总数累计发现的不合规项数量
💡 整改建议总数累计提出的整改建议数量

7.2 风险等级分布

以进度条形式展示低风险、中风险、高风险评估报告的数量分布，直观反映整体安全态势。

7.3 不合规项分类分布

按消防类别（消防通道、设施器材、电气管理等）展示不合规项的数量和占比，帮助识别问题的集中区域。

7.4 高频问题排行榜

列出出现频次最高的具体问题，标注所属类别和出现次数，帮助管理者聚焦优先整改事项。

7.5 月度合规率趋势

以柱状图形式展示每月合规率变化趋势，可追踪消防安全管理工作的改善效果。

提示：统计数据基于系统中所有已完成的评估报告。数据自动更新，无需手动刷新。

8. 常见问题

Q1: 支持哪些图片格式？

支持 JPG、PNG、WebP 等常见图片格式。建议图片清晰度适中，单张不超过 10MB。

Q2: 一次最多可以上传多少张图片？

单次评估模式建议不超过 5 张；分图评估模式不限数量，但评估总耗时与图片数量成正比。

Q3: 评估失败怎么办？

系统会自动重试最多 3 次。如果仍然失败：
① 检查网络连接是否正常
② 等待几分钟后重试（可能是 AI 服务暂时拥堵）
③ 如持续失败，请联系管理员检查 API Key 是否有效或配额是否耗尽

Q4: 评估报告可以导出吗？

可以。报告页面提供"打印报告"和"导出 PDF"两个按钮，支持打印和导出为 PDF 文件。

Q5: 如何自定义评估规则？

进入「规则管理」页面，点击"新增规则"按钮，填写规则信息后保存即可。支持上传 PDF 法规文档自动填充内容。

Q6: 评估结果准确吗？

AI 评估结果基于大语言模型对图片的分析，结合消防法规知识库综合判断。结果仅供参考，重要决策建议结合专业消防人员实地检查。

Q7: 忘记密码怎么办？

请联系系统管理员重置密码。账号和密码由管理员在服务器配置中统一管理。

Q8: 系统支持移动端吗？

当前版本针对 PC 端浏览器（Chrome / Edge）优化。移动端浏览器可以访问但体验可能不佳。
