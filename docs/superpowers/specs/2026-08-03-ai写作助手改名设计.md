# AI 写作助手改名设计

## 目标

将对外平台名称从“领导文稿助手 / Leadership Writing Assistant”改为“AI 写作助手”，并使用不含 `leader` 的正式链接，同时保持已部署账户、身份档案、浏览器本地数据和旧链接可用。

## 设计

- 正式前端路径为 `/ai-writing/`，前端构建基路径与 React Router 基路径同步调整。
- Nginx 在 `/ai-writing/` 提供 SPA 与静态资源；`/leader-assistant` 和 `/leader-assistant/` 使用 302 跳转到新路径。
- 前端显示名称改为“AI写作助手”，英文副标题改为 `AI WRITING ASSISTANT`。
- API 改为 `/api/ai-writing`；为不影响已打开的旧页面，`/api/leader-assistant` 保留为兼容路由，行为与新 API 相同。
- 本地存储键、登录账号、默认身份与导出功能不改动，确保 `wanxin` 和 `wanqin` 现有使用状态不受影响。

## 验收

1. `http://139.224.235.191/ai-writing/` 能打开登录页与工作台。
2. 旧地址会跳转到新地址。
3. 两个账号仍能登录并生成、导出 Word。
4. 新页面与新 API 的对外地址均不含 `leader`。
