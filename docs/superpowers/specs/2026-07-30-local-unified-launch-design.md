# 本地统一启动与路由防护设计

## 背景

AGULAB 官网、通用评判平台和天心区消防安全评估系统在生产环境中由 Nginx 以同域路径提供：

- `/`：AGULAB 官网
- `/evaluate/`：通用评判平台
- `/evaluate_tianxin/`：天心区消防安全评估系统
- `/website-static/`：官网构建资源
- `/api/`：后端接口

当前直接运行 `website` 的 Vite Preview 时，Vite 会把 `/website-static/` 当作网页公开基路径；官网自定义路由则只识别 `/` 等页面路径。两者不一致会导致 Vite 基路径提示、站内 404，以及评判平台链接落到错误端口。

## 目标

提供一个明确、可靠的一键本地启动入口，使本地访问结构与生产环境保持一致，并消除误用单独 Preview 时出现的路径问题。

成功标准：

1. 用户通过一条 PowerShell 命令启动本地完整环境。
2. 启动完成后自动打开官网首页。
3. 官网、通用平台、消防系统和 API 使用同一个本地端口。
4. 直接访问或刷新 `/`、官网子页面、`/evaluate/` 和 `/evaluate_tianxin/` 均正常。
5. 访问 `/website-static/` 不再显示官网站内 404，而是安全返回官网首页。
6. 端口占用、构建失败、后端启动失败时显示明确的中文诊断信息。
7. 不改变现有生产 Nginx 路由、Docker 服务结构及服务器更新流程。

## 推荐方案

采用“本地统一启动入口 + 路由防护”方案。

### 本地统一启动入口

新增一个项目根目录 PowerShell 启动脚本，负责：

1. 定位项目根目录及 Node、npm、Python 运行环境。
2. 检查并构建 `website`、`frontend-public` 和 `frontend`。
3. 检查后端 8000 端口；未运行时启动 FastAPI，已运行且健康时复用。
4. 为同域集成预览选择指定端口；默认端口被占用时给出占用信息并选择下一个可用端口。
5. 启动 `scripts/serve-integration.py`。
6. 轮询官网与 API 健康状态，成功后自动打开浏览器。
7. 在同一终端持续显示服务状态；退出时清理仅由本脚本创建的子进程。

脚本不结束或替换用户已启动的无关进程。

### 路由防护

保留生产环境 `/website-static/` 作为静态资源前缀。集成预览服务器对 `/website-static/` 裸路径做显式跳转或首页回退，但继续按原逻辑提供 `/website-static/assets/...` 等真实静态资源。

官网页面路由继续以 `/` 为根，不把 `/website-static/` 变成正式页面前缀。这样本地集成预览与生产 Nginx 的页面 URL 保持一致。

`/evaluate` 和 `/evaluate_tianxin` 继续规范化跳转到带尾部斜杠的入口，避免相对资源地址产生差异。

### 防误用

更新项目文档，将根目录一键脚本设为唯一推荐的完整本地预览方式。单独运行各前端只用于组件开发，并明确列出其用途和限制。

官网的 Preview 命令不再作为完整站点联调入口。若保留该命令，文档和命令输出必须清楚提示用户使用统一启动脚本查看跨应用链接。

## 生产环境兼容性

本次工作不修改：

- `nginx.conf` 中的生产路由结构
- `docker-compose.yml` 的服务和挂载关系
- 后端 API 路径及认证行为
- 三个前端的生产访问入口
- 服务器构建和更新所依赖的 `dist` 输出目录

路由防护首先在本地集成服务器实现。若官网代码需要增加兼容处理，该处理必须在 `/` 生产根路径下保持无操作，并通过生产路径测试验证。

## 错误处理

- 缺少 Node、npm 或 Python：启动前立即停止并指出缺少项。
- 缺少依赖：提示先安装依赖，或由脚本按明确策略执行安装。
- 前端构建失败：停止启动，不使用陈旧构建结果。
- 8000 端口已占用：先访问 `/api/health`；健康则复用，否则停止并报告占用进程。
- 预览端口已占用：不终止占用进程，选择后续可用端口并显示最终 URL。
- 集成预览启动失败：停止本次新建的后端进程并保留日志。
- 浏览器无法自动打开：服务继续运行，并在终端打印可点击 URL。

## 验证与测试

自动测试覆盖：

1. 集成服务器路径分类和重定向。
2. `/website-static/` 裸路径的安全行为。
3. `/website-static/assets/...` 的静态文件行为。
4. 官网根路径和已知子页面刷新。
5. `/evaluate`、`/evaluate/`、`/evaluate_tianxin` 和 `/evaluate_tianxin/`。
6. API 代理健康检查。
7. 启动脚本的端口选择与错误分支。
8. 三个前端生产构建。

浏览器验收覆盖桌面与窄屏视口，确认首页、导航、跨平台跳转和刷新行为正常。

## 非目标

- 不调整官网视觉设计或页面文案。
- 不改变消防评估业务功能。
- 不增加新的生产服务或外部依赖。
- 不自动修改服务器配置或执行线上部署。
