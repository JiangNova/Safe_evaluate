# 消防安全评估系统 — 前端设计规格

> 日期: 2026-07-23
> 状态: 已确认
> 版本: v1.0

---

## 1. 项目概述

**项目名称**: SafeEvaluate（消防安全评估系统）

**目标用户**: 公安系统消防评估人员

**核心功能**: 上传消防图纸/平面图，选择消防安全规则标准，通过 AI 模型分析生成消防安全评估报告。

**技术栈**:
- 前端: React（单页应用）
- 后端: Python（接千问 API）
- 部署: 内网环境

---

## 2. 设计系统

### 2.1 设计方向

**沉稳专业风** — 浅灰背景 + 深蓝主色。政府/公安工具调性，强调可靠、权威、清晰。

### 2.2 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#1a56db` | 深蓝，按钮、链接、强调元素 |
| 主色浅 | `#eff6ff` | 选中背景、hover 态 |
| 背景 | `#f8fafc` | 页面主背景 |
| 卡片白 | `#ffffff` | 卡片、表格、内容区 |
| 深色 | `#1a2236` | 登录左侧面板、标题文字 |
| 边框 | `#e8ecf1` / `#d1d5db` | 卡片边框 / 输入框边框 |
| 辅助文字 | `#64748b` / `#94a3b8` | 正文辅助 / 占位提示 |
| 合规绿色 | `#16a34a` | 合规标记、通过状态 |
| 警示橙色 | `#d97706` | 整改建议、警告状态 |
| 隐患红色 | `#dc2626` | 不合规标记、消防隐患 |

### 2.3 字体

- 中文: 系统默认（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`）
- 英文/数字: 等宽数字 `font-variant-numeric: tabular-nums`

### 2.4 圆角与间距

- 按钮/输入框圆角: `6-8px`
- 卡片圆角: `10-12px`
- 页面内边距: `24px`
- 卡片内边距: `16-24px`
- 元素间距: `8px` / `12px` / `16px` / `24px`

## 3. 页面结构

### 3.1 登录页 (`/login`)

**布局**: 左右分屏

```
┌─────────────────────┬──────────────────────┐
│                     │                      │
│   深蓝渐变背景       │   浅灰背景            │
│                     │                      │
│      🔥 图标        │   登录系统             │
│    消防安全评估      │   ┌────────────────┐  │
│    ─────            │   │ 账号输入框      │  │
│  智能评估·精准研判   │   └────────────────┘  │
│  保障消防安全        │   ┌────────────────┐  │
│                     │   │ 密码输入框      │  │
│                     │   └────────────────┘  │
│                     │   [ 登 录 ]           │
│                     │                      │

└─────────────────────┴──────────────────────┘
```

- **左侧 (42%)**: 深蓝渐变背景 (`#101b2e` → `#1e3355`)，居中展示品牌图标（火焰 emoji/SVG）、系统名称、副标题
- **右侧 (58%)**: 浅灰背景 (`#fafbfc`)，居中登录表单：标题 + 账号输入 + 密码输入 + 登录按钮 + 授权提示
- **交互**: 表单校验（空值提示），登录失败错误提示，登录成功跳转主页
- **不需要**: 注册、忘记密码、验证码（内网系统，账号由管理员分配）

## 5. 路由设计

| 路径 | 页面 | 是否需要登录 |
|---|---|---|
| `/login` | 登录页 | 否 |
| `/` | 重定向到 `/evaluate` | 是 |
| `/evaluate` | 新建评估 | 是 |
| `/report/:id` | 评估报告 | 是 |
| `/history` | 历史记录 | 是 |

认证方式：登录后后端返回 token，前端存储（localStorage/sessionStorage），后续请求携带 token。Token 过期后跳转登录页。

## 6. 前端技术选型

| 项 | 选择 | 说明 |
|---|---|---|
| 框架 | React 18+ | 用户指定 |
| 构建工具 | Vite | 快速、现代化 |
| 路由 | React Router v6 | 单页路由 |
| 样式方案 | CSS Modules | 组件级隔离，不引入额外依赖 |
| 状态管理 | React Context + useReducer | 场景简单，无需 Redux |
| HTTP 请求 | axios | 拦截器处理 token |
| 图标 | 内联 SVG + emoji | 保持轻量 |
| 文件上传 | react-dropzone | 拖拽上传体验 |

## 7. 非功能需求

- 支持主流浏览器（Chrome, Edge）
- 响应式：桌面端优先（1280px+），暂不需要移动端适配
- 加载态：上传和评估过程显示 loading 状态
- 错误处理：网络错误、超时、认证失败均有用户提示
- 安全性：密码传输加密（HTTPS），token 存储，XSS 防护
