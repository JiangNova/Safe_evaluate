# 通用评判项目卡文案设计

## 目标

将 AGULAB 官网 AI 赋能页的当前项目卡从消防专属项目调整为通用自动合规评判平台，使官网展示与 `/evaluate` 通用平台框架保持一致。

## 文案

- 英文标识：`AUTOMATED COMPLIANCE EVALUATION`
- 标题：`自动合规评判平台`
- 简介：`面向图片材料、法律法规与规章制度，构建可扩展的智能合规评判框架。`
- 能力点：`多类型材料解析`、`法律法规关联`、`规章制度对照`、`结构化评判结果`

## 边界

- 只修改官网项目卡内容，不修改天心区平台。
- 项目卡继续链接到 `/evaluate`。
- 不出现消防、公安、派出所或天心区专属表述。
- 不改变页面布局、配色或交互。

## 验收

- 官网测试和生产构建通过。
- 项目卡显示新的通用文案。
- “立即体验”仍进入 `/evaluate`。
- 桌面页面无布局溢出或控制台错误。
