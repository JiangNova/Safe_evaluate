# AI 写作助手改名 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将领导文稿助手的对外名称与正式 URL 改为 AI 写作助手，同时保持旧链接和既有账号可用。

**Architecture:** 前端以 `/ai-writing/` 作为 Vite 与 React Router 的唯一正式路径，Nginx 提供新 SPA 路由并将旧路径跳转到新地址。后端使用新 API 前缀，同时注册兼容旧 API 前缀的同一组路由，避免旧版浏览器页面立即失效。

**Tech Stack:** React、Vite、React Router、FastAPI、Nginx、Vitest、pytest。

## Global Constraints

- 对外显示名称为“AI写作助手”，英文副标题为 `AI WRITING ASSISTANT`。
- 正式入口为 `/ai-writing/`，地址中不得包含 `leader`。
- `wanxin` 与 `wanqin` 账号、默认身份、本地数据和 Word 导出必须保持可用。
- `/leader-assistant/` 和 `/api/leader-assistant/` 仅作为兼容入口，不再作为正式入口。
