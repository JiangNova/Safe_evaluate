# 领导文稿助手登录与导出修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为领导文稿助手增加隔离登录和预置身份，并导出格式正确、无 Markdown 星号的中文 Word 文档。

**Architecture:** 后端为领导助手单独提供固定账号验证、JWT 签发和路由级鉴权；前端以登录会话为工作台入口，并按 username 给浏览器本地数据命名空间分区。DOCX 导出器统一设置文档样式，并将有限 Markdown 解析成段落与行内 run。

**Tech Stack:** FastAPI、PyJWT、Pydantic、python-docx、React、React Router、Axios、Vitest、unittest。

## Global Constraints

- 保留原有新增、编辑、删除、切换多身份档案的能力。
- 仅提供 `wanxin / wanxin` 和 `wanqin / wanqin` 两个初始账号。
- 档案和历史文稿保持浏览器本地保存，且必须按登录账号隔离。
- 后端接口不得接受无效或过期 token。
- 导出文档不得保留 Markdown 加粗星号。
